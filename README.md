# TorchForge

TorchForge is a micro-orchestration platform enabling real-time data processing dynamic, scalable applications via a centralized Hub and Engine.

TorchForge is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/TorchForge.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

TorchForge is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
